# Журнал изменений

Здесь по-человечески записано, что менялось в проекте и когда.
В отличие от [PLAN.md](PLAN.md), который описывает, как проект
устроен сейчас, этот файл копится со временем: новая запись
добавляется при каждой значимой правке, старые записи никогда
не переписываются и не удаляются.

Новые записи добавляются сверху. Формат простой: дата, а под ней
короткими пунктами, что изменилось и, если это не очевидно,
почему. Мелкие технические правки (опечатка, форматирование)
отдельной записи не заслуживают, для этого есть история Git.


## 2026-09-03

- Добавлен файл `PLAN.md`: полное описание проекта простым языком
  (из чего сделан сайт, как устроены папки), правила ведения
  документации и правила, по которым устроен код.


## 2026-09-01

- Проект разложен по отдельным файлам вместо одного большого:
  `html/index.html` (разметка), `html/css/style.css` (оформление),
  `html/js/app.js` (расчёты). Раньше всё это лежало в одном файле
  и было неудобно искать нужное место.
- Заодно весь код переписан в читаемом виде: без длинных
  однострочных блоков, с отступами и переносами, как обычно пишут
  руками. Расчёты и логика при этом не менялись.


## 2026-08-20

- Из налогового периода убран вариант «Календарный год»: по этой
  форме за целый год отчитаться нельзя, есть только 1-е и 2-е
  полугодие.
- Исправлена ошибка в коде налогового органа. Раньше его можно
  было выбрать из списка и одновременно вписать вручную в соседнее
  поле, оба значения сохранялись одновременно и расходились между
  собой. Теперь это одно поле: можно ввести код напрямую, а для
  Астаны и Алматы, где известны настоящие коды, они подсказываются
  при вводе.


## 2026-08-18

- Сайт впервые опубликован в интернете: https://ustuf.github.io/910/
  Способ публикации по пути пришлось поменять: первый вариант
  (стандартный построитель GitHub) не заработал без объяснения
  причины, поэтому публикация переведена на более современный
  и надёжный способ, через GitHub Actions.
- Добавлен автоматический подбор ставки налога по региону на
  2026 год. Для 13 из 20 регионов (Астана, Алматы и ещё 11 областей)
  настоящая ставка теперь подставляется сама. Там, где город
  и окрестные районы платят по-разному, вместо угаданной цифры
  показывается честное предупреждение.
- Убран разговорный тон у подсказок в форме («программа сама
  подставила», «пожалуйста, узнайте») в пользу сухих, официальных
  формулировок, как в обычной бухгалтерской программе. Цветные
  рамки оставлены только у настоящих предупреждений и ошибок,
  обычные справочные строки стали простым текстом без рамки.
- Первая вкладка формы переименована из «Титульный лист»
  в «Общие данные».
